# legal

複数アプリ共通のプライバシーポリシー・利用規約・お問い合わせページをまとめて管理するリポジトリです。

## 構成

アプリごとにディレクトリを分け、その中にそのアプリの法務ページ一式を置きます。

```
legal/
  vibes/
    index.html   # プライバシーポリシー・利用規約・お問い合わせ（#privacy, #terms, #contact のアンカー付き）
  <次のアプリ名>/
    index.html
```

新しいアプリを作るときは、同じ形式で `legal/<アプリ名>/` ディレクトリを追加してください。

## 公開について

現時点では各ページはまだ実際のドメインにホスティングされていません。App Store Connect等に登録する前に、いずれかの方法で実際のURLを用意する必要があります：

- 静的ホスティングサービス（Vercel, Netlify, GitHub Pagesなど）にこのリポジトリをデプロイする
- 自社ドメイン配下（例: `https://legal.example.com/vibes/`）にアップロードする

## 各ページの仮の値

`vibes/index.html` 内の黄色くハイライトされた箇所（運営者名・制定日）はまだ仮の値です。実際の情報に差し替えてから公開してください。
