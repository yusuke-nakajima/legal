Privacy Policy

プライバシーポリシー

制定日：2026年9月21日

運営者名を記入（以下「当方」といいます）は、ビブス（以下「本アプリ」といいます）における利用者情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 取得する情報

本アプリは、Sign in with Appleによるサインインのみを提供しており、以下の情報を取得します。

情報の種類取得タイミング用途
メールアドレス・氏名Sign in with Appleでの初回サインイン時アカウントの識別、グループ内での表示名
Appleの安定識別子（Apple ID紐付けトークン）サインインのたびに送信再インストール・再ログイン時に同一アカウントとして復元するため
プッシュ通知トークン（Expo Push Token）通知許可時マッチ成立時の通知送信
マッチング履歴（相手・日時・所属グループ・選択した「今、〇〇したい」の内容）マッチ成立時履歴表示、グループ内の利用実績集計
所属グループ情報グループ参加・作成時マッチング対象の絞り込み
アプリ内購入の履歴（トークン購入・サブスクリプション等）購入時トークン残高やプランの反映
クレジットカード番号などの決済情報は当方のサーバーには保存されません。決済はApp Storeおよび決済基盤（RevenueCat）を通じて処理されます。

2. 利用目的

  • 本アプリの提供・維持・改善のため
  • マッチング機能（相手の検索・通知）を提供するため
  • グループ管理者による利用実績・トークン残高の確認機能を提供するため
  • お問い合わせへの対応のため

3. 第三者への提供・委託

本アプリは、以下の外部サービスを利用してデータを処理しています。これらの事業者に対し、業務委託の範囲内で必要な情報を提供します。

  • Google Firebase（Firestore） — アカウント情報・マッチング履歴等のデータベース
  • Amazon Web Services（Lambda / API Gateway） — サーバー処理基盤
  • Expo（Expo Push Notifications） — プッシュ通知の配信
  • RevenueCat — アプリ内課金の管理
  • Google Mobile Ads — 広告配信（下記4項）

4. 広告について

本アプリはGoogle Mobile Ads SDKを使用してバナー広告を表示します。本アプリは非パーソナライズ広告のみをリクエストしており、広告IDentifier for Advertisers（IDFA）へのアクセスや、行動履歴に基づく広告のカスタマイズは行いません。そのためApp Tracking Transparencyの許可ダイアログは表示されません。

5. データの保管期間・削除

取得した情報は、アカウントが存在する期間中保管します。アカウント削除・データ削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。合理的な期間内に対応します。

6. 未成年の利用について

本アプリは社内コミュニケーションを目的とした業務利用アプリであり、18歳未満の方の利用を想定していません。

7. 本ポリシーの変更

本ポリシーの内容は、法令等を踏まえて変更されることがあります。変更後のプライバシーポリシーは、本ページに掲載した時点から効力を生じるものとします。
